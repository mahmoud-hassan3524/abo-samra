# 🍽️ مطعم أبو سمرة | Abu Samra Restaurant

تطبيق ويب عصري وفاخر وعالي الأداء لمطعم **أبو سمرة (شاورما & مشويات سورية)** مبني باستخدام **Vue 3 (Composition API / `<script setup>`)**، **Vite**، و **Tailwind CSS**.

---

## 🌟 الميزات المعمارية والوظيفية (Key Features)

1. **تصميم وهوية بصرية مستخرجة من الشعار الأصلي:**
   - استخراج وتطبيق درجات اللون البرتقالي الناري الفاخر (`#ea580c` و `#f97316`) المتطابقة تماماً مع لوجو المطعم.
   - دعم الوضع الليلي الفاخر (**Dark Mode**) والوضع النهاري النقي (**Light Mode**) مع حفظ التفضيل.
   - طباعة عربية فائقة الجمال مدعومة بخط **Cairo** المخصص و **Outfit** مع مراعاة كاملة لاتجاه القراءة من اليمين لليسار (**RTL**).

2. **بيانات حقيقية مستخرجة بالكامل من صور قائمة الطعام الأصلية:**
   - **سندوتشات الشاورما:** (شاورما دجاج وسط، كبير، ماروخ، ماريا صاج، عيش شامي، كايزر).
   - **سندوتشات السوري:** (مكسيكان حار، شيش طاووق، زنجر، كرسبي، بالعيش الفرنسي).
   - **الوجبات العائلية والصواني:** (وجبة عربي سنجل، دبل، عائلي، وجبة مكس أبو سمرة الملكية، وجبات الكريسبي والشيش).
   - **المشويات على الفحم:** (فراخ مشوية كاملة، نص، أرباع، دجاج مسحب خالي من العظام).
   - **فتات أبو سمرة:** (فتة شاورما، فتة زنجر، فتة كرسبي، فتات بالجبنة - جميعها تقدم مع بطاطس).
   - **بوكسات أبو سمرة الأسطورية:** (بوكس السداد 200ج، بوكس الأكيل 170ج، بوكس الأدرينالين 270ج).
   - **عروض أبو سمرة الحصرية:** (2 شاورما كبير + 1 هدية بـ 185ج، 2 شاورما وسط + 1 بطاطس بـ 145ج، وغيرها).
   - **تريند أبو سمرة:** (تريند الشيبسي، علبة تريند الشيبسي فاهيتا، سندوتش الرجة).
   - **الحواوشي والمقبلات:** (حواوشي سوري وجبنة، لودد فرايز بالشاورما والشيدر، تومية سورية، كول سلو، أرز بسمتي).
   - إمكانية إضافة جبنة موتزاريلا ذائبة (+15 ج.م) كما هو محدد بالمنيو الأصلي.

3. **سلة طلبات متقدمة ونظام حجز تفاعلي (Static Client-side):**
   - سلة طلبات جانبية منزلقة (**Slide-over Cart Drawer**) مع خيارات تحديد نوع الطلب (دليفري 🛵، استلام من الفرع 🛍️، صالة داخلية 🍽️).
   - تخصيص الوجبات عبر نافذة تفاعلية (**Modal**): إضافة جبنة موتزاريلا (+15ج)، تحديد درجة الشطة (عادي / حار 🌶️)، وكتابة ملاحظات للشيف.
   - محاكاة تطبيق أكواد الخصم (`SAMRA10` لخصم 10% أو `WELCOME` لخصم 20 جنيه).
   - حفظ السلة محلياً في المتصفح (**LocalStorage**).
   - احتفال تفاعلي بالمفرقعات (**Confetti Celebration**) عند إتمام الطلب أو حجز مناسبة مع إنشاء رقم مرجعي للطلب.
   - **إرسال الطلب بنقرة واحدة عبر واتساب:** تنسيق الرسالة بالكامل بكافة الأصناف والملاحظات والإجمالي وتوجيهها مباشرة لرقم واتساب المطعم الرسمي (`01157707019`).

4. **قسم تجهيز الحفلات والمناسبات:**
   - نموذج مخصص لتجهيز الحفلات وأعياد الميلاد والعزومات بناءً على إعلان المطعم الأصلي.

5. **معلومات الاتصال المعتمدة:**
   - **أرقام الطلبات:** `01018197684`
   - **رقم الواتساب:** `01157707019`
   - **العنوان:** اللبيني الهرم - شارع السيسي - أمام مركز شباب السيسي، محافظة الجيزة.
   - خريطة تفاعلية للفرع وزر مباشر لفتح الموقع في خرائط Google.

## 🚀 تشغيل المشروع محلياً (How to Run)

1. **تثبيت الحزم (إن لم تكن مثبتة بالفعل):**
   ```bash
   npm run dev
   # أو
   npm.cmd run dev
   ```

2. **بناء المشروع للإنتاج (Production Build):**
   ```bash
   npm run build
   ```

3. **معاينة البناء:**
   ```bash
   npm run preview
   ```
